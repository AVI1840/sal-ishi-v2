# טיוטת מייל לשותפים

**נושא:** אטלס וקטלוג סל אישי: גרסת תצוגה למשוב, לפני הפיילוטים

שלום,

מצורפת גרסת תצוגה של אטלס וקטלוג הסל האישי להזדקנות מיטבית. הכלי מתרגם את ההכרעות של צוות היישום לכלי עבודה: רכזת ומנהלת שכונה בונות קטלוג לשכונה ובודקות כיסוי, והמטה מאחד את הפיילוטים, רואה מחירי ייחוס ומייצא קטלוג מאושר לאינטגרטור.

הכלי מבוסס על סיכום מפגש 2 (26.10.2026), פגישת החשכ"ל (28.10.2026) ואטלס פיילוט ירושלים. ערכים שעוד לא הוכרעו מסומנים בכלי "הצעה" ויידונו במפגש 3 (26.11.2026).

**איך נכנסים**
- משטח שטח: [קישור]/field/
- משטח מטה: [קישור]/hq/
- אם הקישור חסום ברשת שלכם: שני קבצים מצורפים (אטלס-סל-אישי-שטח.html ואטלס-סל-אישי-מטה.html). פותחים בדפדפן Chrome או Edge, בלי התקנה.

**חשוב**
- כל הנתונים סינתטיים. אין לכתוב בכלי שום פרט מזהה של תושב.
- מה שתזינו נשמר רק בדפדפן שלכם.

**איך נותנים משוב**
1. התחילו במסך "מדריך לשותפים". שם יש רשימה של מה כדאי לנסות.
2. בכל מסך יש כפתור "הוספת משוב".
3. בסוף, במסך "המשוב שלי", הורידו קובץ Excel ושלחו אותו אליי עד [תאריך].

נשמח במיוחד לשמוע: האם הכללים תואמים את ההכרעות כפי שאתם מבינים אותן, האם המונחים ברורים לרכזת בלי הדרכה, ומה חסר או מיותר.
