## אירוע

שדות משותפים: `id`, `at` (ISO), `actor` (`citizen`, `companion`, `system`), `citizenId`, ולפעמים `onBehalf`.

- `citizenId` הוא מזהה בדוי של הספק. **אף פעם לא מספר זהות.** אין שדות שם, טלפון, כתובת או תאריך לידה, ובדיקה אוטומטית אוכפת זאת (`PILOT_FORBIDDEN_KEYS`).
- `onBehalf` (הרשאת פעולה): `{ consent: "verbal", readBack, confirmedAt }`. `readBack` הוא מה שהמלווה הקריאה לאזרח לפני האישור. זה לא ייפוי כוח.
- `coveredShekel`, `copayShekel` בהזמנה הם להמחשה. הסכום המחייב נקבע אצל הספק.

## ממשקי חיבור לספק

```ts
// src/pilot/sync.ts
interface PilotSyncAdapter {
  name: string;
  push(events: PilotEvent[]): Promise<{ accepted: string[] }>; // מה שלא התקבל נשלח שוב
  pull?(since: string | null): Promise<PilotEvent[]>;
}
setSyncAdapter(myAdapter);
```

```ts
// packages/core/src/sync/SyncAdapter.ts: קטלוג, seed וחבילות פיילוט (קיים מ-0.3)
```

הסנכרון רץ לבד כשהחיבור חוזר. מה שממתין מוצג למלווה ("3 שינויים ממתינים לסנכרון").
