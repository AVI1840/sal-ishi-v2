# הרצה ובדיקות

דרישות: Node 20, npm.

```bash
npm ci
```

| מה | פקודה | כתובת |
|----|-------|-------|
| אזרח ומלווה (פיתוח) | `npm run dev` | http://localhost:5173 |
| שטח (פיתוח) | `npm run dev:field` | http://localhost:5174 |
| מטה (פיתוח) | `npm run dev:hq` | http://localhost:5175 |
| בנייה מלאה (כמו באתר) | `npm run build:all` | `dist/`, כולל `dist/offline/` |
| בדיקות ליבה | `npm run test:core` | 214 בדיקות |
| בדיקות הכלי לאזרח | `npm test` | 41 בדיקות |
| קצה לקצה (בונה ובודק) | `npm run test:e2e` | 17 תרחישים, נייד ומחשב |
| קצה לקצה בלי בנייה | `npm run e2e` | |
| עדכון JSON Schema | `npm run schema -w @sal-ishi/core` | `schema/` |

בלי חיבור להורדת דפדפן לבדיקות: `PW_CHROMIUM=<נתיב ל-chrome.exe> npm run e2e`.

## מה הבדיקות מכסות

- **ליבה:** כללים, מדדים, תקן קליטה מול JSON Schema, פרטיות הייצוא, אירועי פיילוט מול JSON Schema, פנקס למידה, ייבוא נתוני 0.4.
- **הכלי לאזרח:** מנוע ההתאמה (golden), גזירת מצב מאירועים, ארנק וביטול, מיון תיק המלווה, עברית פשוטה (בלי "נקודות", "מיצוי", "חדירה" ועוד, משפטים עד 18 מילים), אותם מפתחות בשלוש השפות, בלי em dash.
- **קצה לקצה:** מבחן הסבתא, מטרות לחיצה של 48 פיקסלים, אישור ודחייה בין לשוניות, הרשאת פעולה, אשפוז, איפוס, רשת חלשה, שפות, 200 אחוז טקסט, axe על 21 מסכים, נתוני 0.4 במטה, עבודה בלי אינטרנט.

## הדגמה או פיילוט

`public/app-settings.json`, השדה `mode`: `demo` (דמויות, נתוני פתיחה בדויים, איפוס) או `pilot`. אין הבדל בקוד. את הקובץ אפשר להחליף באתר בלי בנייה.

## פריסה

דחיפה ל-`v0.5` מריצה את "Next build" (בדיקות, בנייה, קצה לקצה), ובסיומו "Deploy to GitHub Pages" מ-main מפרסם את `SITES`. החלפה ל-0.5 בשורש: לשנות את `SITES` ל-`"main:. v0.4-stable:v04"` אחרי מיזוג `v0.5` ל-`main`.
