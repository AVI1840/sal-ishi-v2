# ארכיטקטורה

## בקצרה

אתר סטטי (GitHub Pages), בלי שרת ובלי התחברות. כל משטח שומר את הנתונים שלו בדפדפן (IndexedDB, ונסיגה ל-localStorage). מה שעובר בין משטחים ולספק עובר כקבצים לפי JSON Schema.

```
           ┌────────────── packages/core ──────────────┐
           │ seed והגדרות, כללים, מדדים, תקן הקליטה,   │
           │ אירועי פיילוט, פנקס למידה, אחסון, סנכרון  │
           └───────┬──────────────┬──────────────┬─────┘
                   │              │              │
   apps/field (שטח)   apps/hq (מטה)   src/ (אזרח ומלווה)
   רכזת הפיילוט      ביטוח לאומי       src/pilot
        │  חבילת פיילוט  │ קטלוג מאושר      │ אירועים
        └──────קובץ──────┘─────קובץ─────────┘──────▶ ספק (PilotSyncAdapter)
                         └── תקן קליטת מפעילים 1.1 ──▶ ספק העל
```

## מאגר אחד, npm workspaces

| תיקייה | מה | טכנולוגיה |
|--------|-----|-----------|
| `packages/core` | כל הלוגיקה, בלי React. מקור האמת לסכמות (zod) | TypeScript, zod |
| `packages/ui` | רכיבים משותפים לשטח ולמטה, מערכת העיצוב של ביטוח לאומי, פנקס הלמידה | React |
| `apps/field` | משטח השטח: קטלוג לשכונה, מבחן כניסה וכיסוי, חבילת פיילוט | React, Zustand |
| `apps/hq` | משטח המטה: איחוד, מחירי ייחוס, כללים, סקירה, ייצוא, יומן ביקורת | React, Zustand |
| `src/pilot` | חוויית האזרח והמלווה (0.5) | React, CSS על טוקני BTL |
| `src/domain` | מנוע ההתאמה (5 שכבות) | TypeScript |
| `src/` (שאר) | מסכי ההאקתון, נטענים רק ב-`VITE_EDITION=hackathon` | React, Tailwind |

## חוויית האזרח והמלווה (`src/pilot`)

- **אירועים כמקור אמת:** כל פעולה נרשמת כאירוע (`packages/core/src/pilotEvents.ts`). הזמנות, בקשות וביקורים נגזרים מהאירועים (`src/pilot/model.ts`, `derive`). האירועים הם גם יומן הביקורת וגם מה שנשלח לספק.
- **סנכרון:** `src/pilot/sync.ts`. ברירת המחדל: מתאם מקומי והורדת קובץ. ספק מממש `push` ומחבר עם `setSyncAdapter`.
- **הגדרות:** `public/app-settings.json` (הדגמה או פיילוט, שם המלווה, סדר המיון, סיבות אישור). כללי התכנית ב-seed (`packages/core/seed/`).
- **שפות:** `src/pilot/i18n/` (עברית, וערבית ורוסית כטיוטה [לאמת]).
- **בלי רשת:** `public/sw.js` (service worker בתחום התיקייה), "הכנה לעבודה בלי אינטרנט" בדף הדמויות.

## גרסאות באתר

`.github/workflows/deploy.yml` בונה כמה גרסאות זו לצד זו לפי `SITES`: היום `main` בשורש ו-`v0.5` ב-`/next/`. הגרסאות חולקות מקור (origin), ולכן 0.5 שומר במאגרים עם סיומת `-v05` ומעתיק נתוני 0.4 פעם אחת בלי לכתוב עליהם (`openVersionedStore`).

## מה לא כאן בכוונה

נקודות חיות, יתרות, תשלומים, רישום אזרחים, אימות נוכחות, שרת, התחברות. אלה בפלטפורמת הספק.
