# @sal-ishi/core

ליבה משותפת לאטלס וקטלוג סל אישי (גרסה 0.4): מודל נתונים, seed, מנוע כללים, מדדים, `SyncAdapter` ותקן קליטת המפעילים. משמשת את משטח השטח, משטח המטה והכלי לאזרח.

```bash
npm run test:core        # מהשורש
npm run typecheck:core
```

## החלטות פרשנות (לאישור)

1. **פרטי ספק יחיד למטה:** לפי `settings.supplier_contact_to_hq` (הוכרע 28.10.2026, `true`). ב-`catalog_export` ובקטלוג לאזרח הספק עובר כקוד וסוג בלבד, בלי שם, גם לחברה או לעמותה, כמו בחוזה.
2. **תוספות למודל:** `Supplier.authority` (מפתח המיזוג במטה) ו-`NeighborhoodMonth.enrolled` (מספר מחזיקי הסל בשכונה בחודש, המכנה של המיצוי). שניהם מספרים מצטברים או קודים, לא מידע אישי.
3. **מזהים:** מזהי שירות ושכונה ייחודיים בין רשויות (המשטח מייצר UUID). מיזוג עם התנגשות נעצר ומוצג.
4. **חבילה מחליפה:** חבילה מחליפה את נתוני הרשות בשכונות שמופיעות בה. שירות שנעלם ממנה מוצג כ"הוסר" לפני המיזוג.
5. **רשימה סגורה (שלב 1 במבחן הכניסה):** קטגוריה או סוג שירות שלא קיימים ב-seed, קטגוריה בשכבת "בחוץ", או איכות חיים בלי כלל ב-`qol_rules`.
6. **שדה החובה "הגעה":** נחשב קיים כשיש לשירות לפחות רשומת פעילות חודשית אחת.
7. **התראת תת-תחום:** לפי `alert_if_below_floor`, כלומר התראה כשיש ב-2.2 פחות מ-`core_floor` שירותים רציפים. אם הכוונה הייתה "אין אף שירות", זה שינוי של שורה.
8. **`floor_applies_to_regular`:** לא בשימוש. לא ברור מה הוא אמור לשנות.
9. **התראת תת-תחום:** עודכן (29.10): הסף ב-`subarea_alert_min` (ברירת מחדל 1, כלומר "אין אף שירות"), במקום הרצפה המלאה. נוסף מדד רוחב (`subcategory_breadth_min`).
10. **היקף שירות:** שירות ברמת רשות או אזורי נספר בכיסוי של כל שכונות הרשות. שירות ארצי לא נספר ברצפה, ומופיע בקטלוג של כל שכונה.
11. **דירוג ספקים:** ההערכה הרבעונית האחרונה, משוקללת לפי `supplier_rating_weights`. מוצג ומזין את ההתאמה, לא חוסם, ולא נכנס לייצוא לספק העל.
12. **ביקוש בקטלוג לאזרח:** רמה (גבוה, בינוני, נמוך) לפי שיא המשתתפים בחלון. מתחת לסף התא הקטן אין רמה, כך שלא נחשף מספר קטן.

### גרסה 0.4: מודל התשלום של החשכ"ל (הוכרע בשלב 0, 29.10.2026)

13. **ה-seed:** 0.4 כמו שהגיע, ועוד ההכרעות של 28.10 ו-29.10 שלא היו בו (פרטי ספק למטה, משקלות התאמה, כללי בחירה, דירוג, תחרות, רוחב, סף תת-תחום). seed שמור מגרסת בסיס ישנה (0.3) מוחלף ב-0.4 המובנה, כי מבנה ההגדרות השתנה. seed של 0.4 שהמטה פרסם (0.4.1 ואילך) נשמר, ומפתחות חסרים בו מושלמים.
14. **דירוג ספקים:** כלי פנימי של הרשות והמטה, לא בתקן קליטת המפעילים. אפשר לכבות אותו עם `supplier_rating_enabled`. הדירוג המחייב אצל ספק העל.
15. **חדירה:** משתתפים פעילים וזכאים ברמות 1 עד 3 הם שדות מצטברים בשכונה ובחודש (`activeParticipants`, `eligible`), מדוח ספק העל. מנתוני השירותים אי אפשר לדעת מי השתתף ביותר משירות אחד. ההגדרה "פעיל" נקראת מההגדרות. מתחת לסף התא הקטן הספירה מוסתרת.
16. **פריסה:** כל קטגוריות הליבה שנבדקות ברצפה ירוקות. מוצרים לא נבדקים ברצפה (`products_count_in_floor`), ולכן נבדק בנפרד שיש מוצר ארצי אחד לפחות.
17. **מחיר ייחוס מחייב:** הקטגוריות והרשויות ב-`reference_price_binding_scope`, ריק כברירת מחדל. "אזור" הוא רשות, גם במדד המחיר לשעה. במצב `preactivated_low_competition` נספרים ספקים שונים באותה קטגוריה ושכונה. הארנק מכסה עד מחיר הייחוס, לפי דרגת ההשתתפות.
18. **שעות ביטול:** לשירות פרטני ולשירות מרחוק אין ערך (null), ומוצג "טרם נקבע".
19. **תקרת מוצרים:** 25% מהארנק הרבעוני, 375 נקודות.
20. **מוצרים:** פטורים משעות שירות ומאופן מתן, ואין להם תנאי ביטול. בהדגמה שובר נספר כשעה אחת.
21. **אשפוז:** קבוצה לפי `hospitalization_refund.group`, וכל השאר (פרטני, בית, מרחוק) לפי `individual`.
22. **שירות בלי שדות 0.4:** נשאר בקטלוג לאזרח עם null, לא נכנס לתקן קליטת המפעילים (מופיע כ"דורש השלמה"), ומופיע ברשימת ההשלמות. שום שדה לא מתמלא לבד: אופן המתן והשער למלווה מוצעים לאישור.
23. **חלוקת הנקודות:** בתקן ובקטלוג לאזרח, כמה מכוסה מהארנק וכמה על הקשיש (`coveredPoints`, `copayPoints`), ולפי מה (`copayBasis`). כך שינוי של `qol_mode` או `reference_price_mode` משנה מיד את הייצוא.

### תקן קליטת מפעילים
`operator_onboarding_standard` 1.1 מחליף את `catalog_export` 1.0. ה-JSON Schema ב-`schema/operator_onboarding_standard_1.1.schema.json` (בשורש המאגר) נגזר מסכמת ה-zod. אחרי שינוי בסכמה: `npm run schema -w @sal-ishi/core`. בדיקה אוטומטית מוודאת שהקובץ מעודכן ושכל ייצוא עובר אותו עם ajv.

נקודת כניסה לכלי המרכזי: `@sal-ishi/core/citizen` (בלי SheetJS).
